## Key findings

1. **Class fit — High.** EPA Size Class Small SUV 4WD, standard Symmetrical AWD, 8.7" clearance (9.2" Wilderness). Direct rival to RAV4/CR-V/Tucson.
2. **Range PASS (except Wilderness) — High.** Gas 33hwy x 16.6 = 548mi PASS; Sport/Touring 32 x 16.6 = 531mi PASS; Hybrid 34hwy x 16.6 = 564mi, EPA total 581mi PASS. Wilderness 28 x 16.6 = 465mi FAIL.
3. **Safety TSP → TSP+ — High.** 2023-24: TSP (17yr run 2007-23). 2025 non-Wilderness: 2024 IIHS TSP+. 2026 incl Hybrid: 2025 IIHS TSP+. Wilderness excluded.
4. **Space — High.** Cargo 28.9 / 74.2 max (Hybrid 69.1 max) — bigger than XC60 21.6 / NX 22.7, smaller than RAV4 37.5 / Tucson 38.7 best. Rear legroom 39.4" — 2nd best behind Tucson 41.3".
5. **Heated / ADAS gate like RAV4 — High.** Heated from Premium up (skip Base). EyeSight ACC std all; BSM/RCTA optional Premium, std higher — Base has neither, same penalty as RAV4 LE.
6. **Reliability / CPO / recalls — Medium-High.** CR more-reliable 2023-24, average 2025 (redesign). Subaru CPO remainder 3/36 + 7/100 powertrain $0 ded. Recalls LOW: driveshaft 23-24 (4701 units), coolant-fire 2024, 3x on 2025.
7. **PNW pricing — Medium.** Gas CPO ~$24-32k (competitive with RAV4 $30-37k, Tucson ~$25.5k). Hybrid new $36.6-43.3k MSRP, CPO thin (late-2025 only).
