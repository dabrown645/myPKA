## Key findings

1. **Accord Hybrid safest bet — High.** Only sedan TSP+ 2022/23/24 + 2025-26 TSP+. 11th-gen side structure Good. Honda Sensing + BSM std all hybrid trims.
2. **Camry Hybrid range king — High.** LE 51/53/52 x 13.2 = 686mi total, XLE/XSE 44/47/46 x 13.2 = 620mi. Toyota Hybrid System 208hp, 200k+ reputation. Trunk 15.1 (battery intrudes), 60/40 not flat, BSM opt LE/SE.
3. **Sonata Hybrid value but safety-gated — High.** SEL 44/51/47 x ~12.1 = 620mi, Blue 50/54/52 = best MPG. 2024 TSP only (Poor updated moderate overlap — driver chest). 2025 TSP+ only post-Nov 2024 build. 10yr/100k $50 ded, no CPO comprehensive extension.
4. **K5 out — Medium-High.** Gas-only 2023-25 (1.6T/2.5T, ~29-31 combined), no hybrid, no IIHS award in 24/25 pulls. Fails 40mpg household target + TSP minimum.
5. **Legacy niche — Medium.** Final gen ends 2025. Std AWD (PNW bonus), 26/35/30 x 16.6 = 581mi PASS, 2024 Outback TSP (wagon) — Legacy sedan marginal/untested in pulls. 30 combined misses hybrid economy, CVT drone.
6. **Altima out — Medium-High.** 27/39/32 x 16.2 = 631mi PASS on paper, but no TSP/TSP+ in 24/25 midsize lists, ProPilot BSM SV+ only, CVT reliability flags.
7. **Mazda6 out-of-scope — High.** Discontinued US 2021. Zero 2023-25 CPO inventory. Cannot score in 1-3yr window.
