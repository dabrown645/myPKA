### Paperclip vs myPKA

Paperclip (paperclipai/paperclip, 55k+ stars) is an open-source multi-agent orchestration framework that treats AI agents like a virtual company (CEO → Engineer → QA) with heartbeat coordination, embedded Postgres, and a React dashboard. myPKA is a Personal Knowledge Management scaffold — an Obsidian-compatible markdown folder with an AI team that helps you journal, manage contacts, and track life goals.

**Key differences:**
- Paperclip = general-purpose agent orchestration; myPKA = domain-specific PKM
- Paperclip uses Postgres; myPKA uses plain markdown files
- Paperclip has a React dashboard; myPKA works in Obsidian or any text editor
- Both use multi-agent team metaphor and are LLM-agnostic, but solve different problems

### Paco Cantero's mindset and its relation to myPKA

Paco Cantero (Co-Founder & COO of Paperless Movement, computer science engineer, runs 4 companies) holds a systems-over-tools philosophy captured in his X bio: *"AI doesn't fix broken productivity systems. It amplifies them. I help professionals build the productivity system first."*

His core themes:
- **From PKM to PKA** — coined the shift from Personal Knowledge *Management* to Personal Knowledge *Assistance*
- **Systems first, tools second** — build the ICOR framework, then let AI layer on top
- **Tool-agnostic** — the system should work regardless of which LLM or app you use
- **Structures that run themselves** — procedures become autonomous through well-designed architecture

myPKA is the concrete implementation of this mindset: the ICOR methodology (Input → Control → Output → Refine) baked into a folder structure, with an AI team that assists rather than requiring manual management, all in portable plain markdown.
